# LocalTypst — download

Qui ci sono solo gli installer di LocalTypst e il file `latest.json` che l'app usa per gli aggiornamenti automatici. Il codice sorgente non è pubblico.

Scarica l'ultima versione da **[Releases](../../releases/latest)**:

- **Windows:** `LocalTypst_Setup.exe` (installer consigliato) oppure `LocalTypst.exe` (portabile)
- **Fedora:** `LocalTypst-linux-x86_64.rpm` → `sudo dnf install ./LocalTypst-linux-x86_64.rpm`
- **Ubuntu/Debian:** `LocalTypst-linux-amd64.deb` → `sudo apt install ./LocalTypst-linux-amd64.deb`
- **Altre distribuzioni Linux:** `LocalTypst-linux-x86_64.AppImage` (rendilo eseguibile e avvialo)

Dopo la prima installazione gli aggiornamenti arrivano da soli dall'app.
